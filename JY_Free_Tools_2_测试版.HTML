    网金工具箱 PRO 更新日志

    [V1.8.0] 2026/07

    • 新增：「数据复刻模式」及可视化调度弹窗，支持一键提取玩家全量信息与武学进度，并智能转化为带有区组参数的无损复刻指令。
    • 新增：全量物品 DB 智能检索系统并网，内置逾 23,000 条物品元数据，在【发放道具】输入框唤醒丝滑的「名称 / ID」双通道模糊检索。
    • 重构：「数据复刻引擎」底层排版架构，重塑指令生成标准。
    • 优化：特殊武功熟练度溢出算法，忽略初次获得武功时的 100 点底层初始值，且仅当数值突破基础阈值时（>100）生成安全有效的增量指令。
    • 重构：自适应悬浮定位下拉面板，突破父级容器包裹限制，支持智能视口触界反弹（防遮挡向上自动展开）。
    • 优化：系统层级植入全局 ESC 快捷侦听拦截器，支持一键脱离任何激活态模态框（含格式输出面板与数据复刻面板）。
    • 修复：基础武功在提取时因 JavaScript 底层数字 0 的布尔假值（Falsy）判定陷阱，导致「基本刀法」编号映射错位与输出错乱的问题。
    • 修复：一阶/二阶生活职业代码字典的映射防呆逻辑，完善对日月星前缀的智能剥离算法，并静默拦截 0 级初始技能的无效输出。

    [V1.7.0] 2026/07

    • 新增：推出「多活动区块」沙盒管理引擎，支持创建、重命名、切换与无损销毁多个独立的活动配置环境，实现底层数据的绝对隔离与多线程运作。
    • 新增：构建「关联消耗」主从绑定架构，允许将大量子武学的消耗逻辑链式绑定至主干武学，实现“一次修改，全局同步生效”的矩阵式管理。
    • 新增：全新「同类武学等级互换」转换模式与专属调度弹窗，支持跨武学间的等级无损转移，并自动生成双向对调格式代码。
    • 重构：「当前已保存配置」列表渲染引擎，支持按五大类别（全局武学/技能、自定义武学/属性/技能）自动分类与智能缩略，并加入永久驻留的 🔗 串联标识。
    • 重构：配置标签底层交互机制，全面摒弃 JS 行内样式注入，采用纯 CSS 引擎接管静态、悬浮与激活状态，完美兼顾亮/暗双主题对比度。
    • 优化：【一键复制输出结果】与【DELETE ALL】等核心/高危操作组件，全面升级为“微透流金”高定版 UI 与系统级防误触警示面板。
    • 优化：全局键盘监听防线，引入「层级阻断器」，支持 ESC 精准关闭顶层弹窗而不误伤底层面板；新增 Space 空格键秒关系统警告功能。
    • 优化：「配置中枢」控制面板布局，引入 CSS 伪元素引擎自动渲染动态垂直分割线，并实现所有数值类输入框文字完美居中。
    • 修复：因底层缺失 getSkillDisplayName() 组装函数及 isTransferApplicable 变量，导致点击基础武学时 JS 引擎崩溃、面板假死的严重级 BUG。
    • 修复：隐藏状态下的【配置模式】单选框残留脏数据问题，彻底根除因底层数据不一致导致的【保存配置】按钮误判及无限亮起黄灯的连环漏洞。
    • 修复：一键生成代码前的最终安检策略，废弃极其脆弱的“字眼扫描”机制，启用基于“存放位置面板真实物理显隐状态”的绝对安检防线。
    • 修复：补齐了目标标签列表在切换数据源后的生命周期回调刷新指令，并恢复了标签的“点击反选”机制，确保用户可随时安全退回未配置状态。

    [V1.6.0] 2026/07

    • 新增：全面接入「生活技能」解析体系，支持一阶及二阶（含日/月/星系别）技能的独立差值运算与专属排版输出。
    • 新增：配置中枢增设【全局配置「技能」】层级，支持一键接管并套用所有未独立配置的生活技能消耗方案。
    • 新增：数据解析引擎扩展，完整覆盖玩家基础信息（账号、实战、历练等）及七大先天属性的精准抓取与差值计算。
    • 重构：格式代码拼接逻辑，全面启用“先删后发”的安全输出标准，并支持动态绑定扣除物品的存放位置。
    • 重构：全量缓存清理引擎，对接底层系统宏变量销毁硬盘级存档，彻底解决刷新后数据“幽灵复活”的问题。
    • 优化：输出面板 UI 动态感应机制，【存放位置】模块将严格基于真实扣除道具的有无实现瞬间无痕显隐。
    • 修复：底层数组索引 0 触发的布尔假值判定陷阱，解决「方案1」中消耗道具被系统静默跳过的严重异常。
    • 修复：数据文本清空重贴场景下，因旧状态未释放导致的“幽灵数据残留”及武学勾选数量翻倍错误。
    • 修复：生活技能在格式输出面板中，错误继承并携带“武功调整”前缀分类的视觉排版异常。

    [V1.5.0] 2026/07

    • 重构：界面按钮与图标体系，全面启用专属 SVG 矢量图标及高对比度样式。
    • 重构：统计摘要面板排版引擎，核心数据强制单行横向对齐显示，增设视觉分隔符。
    • 优化：扩展「综合耗时」模式数据列，支持并行展示多维度对比，并同步更新 Excel 导出结构。
    • 修复：主题模式控制按钮在激活状态下图标色彩对比度失效的问题。
    • 修复：底层节点动态注入导致数据文本强制换行截断的排版异常。

    [V1.4.0] 2026/07

    • 新增：大类进阶消耗规则支持多阶梯判定，系统按数量降序优先匹配最高级规则。
    • 新增：配置方案支持 .json 格式本地导出与导入（提供合并与覆盖双模式）。
    • 优化：完善跨分类武学（如兼具特技与石壁属性）的解析与规则匹配链路。
    • 优化：全站弹窗与按钮的交互样式，移除系统默认控件表现。
    • 修复：添加发奖区组冲突的排他判定机制，检测到冲突时将自动锁定输出功能。

    [V1.3.0] 2026/06

    • 重构：界面整体迁移至深色主题，采用定制 SVG 矢量图标替换原系统 Emoji。
    • 重构：调整数据统计框体的排列比例，使其在一行内自适应平分显示。
    • 新增：配置中枢（V1.0），支持通过下拉搜索与图文列表选择对应道具。
    • 新增：格式代码一键输出模块，建立从数据解析到参数配置的自动化生成链路。
    • 修复：自修与天悟计算的阶段性截断机制，修正外功、内功、格挡的初始状态计算基准。

    [V1.2.0] 2026/05

    • 新增：引入顶层数据漏斗面板，支持按 7 大核心武学分类快速筛选、剔除干扰项。
    • 新增：引入基础进阶消耗规则框架，支持设定单项达标门槛触发额外发放。
    • 优化：重写底层批处理逻辑，提升大批量武学数据并行计算时的稳定性。

    [V1.1.0] 2026/04

    • 新增：引入 localStorage 本地缓存机制，支持配置方案无感驻留。
    • 修复：将原“一键统计未满级格挡”功能逻辑更正为“一键统计未学习格挡”。
